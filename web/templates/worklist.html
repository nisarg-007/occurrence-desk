How the ranking works

Priority is a score out of 100, recomputed on every read, from four things: how severe the worst hazard on the report is (45 points), how confidently the report is matched to a real flight (25), how recently it was filed (20), and whether a manager flagged it (10).

Nothing is hidden: every report shows its own arithmetic. The list is ordered by priority, then report date, then id, and paged on that position rather than by row offset, so page 100 costs the same as page 1.
